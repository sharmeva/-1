# Сбер Здоровье: прототип приложения

Демонстрационный прототип мобильного приложения: запись к врачам, анализы (результаты, динамика, доступ врачу, скачивание, ИИ-консультация), вход по номеру телефона и Сбер ID. Это учебный макет, не официальный продукт Сбера.

## Как опубликовать на GitHub Pages (бесплатно, без установки программ)

1. Зайдите на https://github.com и создайте новый репозиторий (New repository). Название любое, например `zdorovie`. Выберите Public.
2. Распакуйте архив на компьютере. Загружать нужно файлы, а не сам архив: GitHub не распаковывает zip.
3. В репозитории нажмите **Add file → Upload files**, перетащите всё содержимое распакованной папки (`index.html`, `server.py`, `README.md`, `.nojekyll`, `.gitignore`, `start-…` и папку `data`) и нажмите **Commit changes**.
   Скрытые файлы `.nojekyll` и `.gitignore` могут не отобразиться в проводнике. Они необязательны, приложение работает и без них.
4. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите **Source: Deploy from a branch**, ветка **main**, папка **/(root)**, нажмите **Save**.
5. Через 1–2 минуты страница будет доступна по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Как это хранит данные

Опубликованная на GitHub Pages версия хранит данные **только в браузере** того, кто её открыл (профили, анализы, загруженные файлы). Они не попадают в репозиторий и не видны другим людям. Данные нельзя синхронизировать между компьютерами автоматически. Переносить их можно через **Профиль → Экспорт данных / Импорт данных** (файл `.json`).

Файл `zdorovie-data-and-logins.json`, который идёт отдельно от этого архива, можно импортировать на экране входа («Импортировать данные с другого компьютера»). В нём демо-аккаунт и его анализы.

## Что работает на GitHub Pages

- Работает: вход, профили, анкета, записи к врачам, корзина, каталог, анализы, динамика, доступ врачу, ручное добавление, скачивание (CSV, TXT, JSON, PDF, HTML), сохранение в браузере, экспорт и импорт.
- Не работает: полноценная ИИ-консультация и распознавание фото и PDF. Они доступны только в версии, опубликованной на платформе Claude. На GitHub ИИ-чат отвечает простыми шаблонами по вашим анализам.

## Локальный запуск с хранением в папке data (по желанию)

Нужен Python 3. Запустите `start-windows.bat` (Windows) или `./start-mac-linux.sh` (macOS и Linux), откроется http://127.0.0.1:8765. Данные будут сохраняться в папку `data/` рядом с приложением. Файл `.gitignore` не пускает эту папку в репозиторий.

## Важно про безопасность

- Репозиторий и сайт на GitHub Pages **публичны**. Не загружайте туда настоящие персональные и медицинские данные, пароли и ключи.
- Логин и пароль демо-входа записаны в коде открытым текстом, это только демонстрация. Настоящего хранения паролей, SMS и серверной проверки в прототипе нет.
